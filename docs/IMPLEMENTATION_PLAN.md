# CivicProcure Implementation Plan

CivicProcure v0.1.1 keeps the deterministic v0.1 foundation aligned to civiccore==0.3.0: runtime shell, sample RFP drafting, proposal comparison, exception extraction helper, scoring summary helper, award-packet checklist, and public sample UI.

Later releases add local procurement template configuration, live vendor portals, CivicContracts file links, staff review queues, submission workflow integrations, and production data governance.
