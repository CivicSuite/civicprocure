CivicProcure User Manual
========================

For Non-Technical Users
-----------------------

CivicProcure helps city staff keep solicitation drafts, proposal notes, exception flags, scoring summaries, staff review queues, board memo inputs, CivicClerk/CivicContracts context references, award-packet records, and API-backed public and staff UIs organized.

Current state: 0.2.0 local-first procurement support and staff review queue runtime. CivicProcure saves generated RFP drafts, award-packet checklists, and staff review queue records in a default local SQLite database unless IT configures CIVICPROCURE_WORKPAPER_DB_URL for an explicit database. Staff-only review routes also require CIVICPROCURE_STAFF_API_KEY.

CivicProcure does not provide official vendor evaluation decisions, legal advice, live vendor portals, live LLM calls, e-procurement submission portals, award decisions, or procurement system-of-record updates. Staff own every decision.

For IT and Technical Staff
--------------------------

CivicProcure is a FastAPI Python package pinned to the published civiccore v1.2.0 release wheel. It exposes RFP draft, proposal comparison, exception extraction, scoring summary, award packet, procurement-review context, adversarial local mock, staff review queue, integration contract, staff UI, and readiness endpoints.

Set CIVICPROCURE_DATA_DIR to choose the default local SQLite-backed workpaper data directory, or set CIVICPROCURE_WORKPAPER_DB_URL when IT needs an explicit SQLAlchemy database URL. Use civicprocure-db-status to initialize/check explicit schema. /ready and /api/v1/civicprocure/readiness report ready when the local schema is available.

Run:

python -m pip install https://github.com/CivicSuite/civiccore/releases/download/v1.2.0/civiccore-1.2.0-py3-none-any.whl
python -m pip install -e ".[dev]"
python -m pytest -q
bash scripts/verify-release.sh

Architecture
------------

CivicProcure depends on CivicCore. CivicCore does not depend on CivicProcure. CivicProcure v0.2.0 uses local-first staff-gated persistence, review-required context packets for CivicClerk/CivicContracts references, staff review queue records, and adversarial local mocks for integration-depth validation.
